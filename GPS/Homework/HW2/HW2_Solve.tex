\hspace*{2em} When observing the differences between the results of SP3 and the yuma almanac,
if we treat SP3 data as our truth data we would have differences of up to $1 \, \mathrm{km}$
as observed in Figure \ref{fig:residuals}. Although large, if we consider the MEO orbit of the GPS
constellations and the fact the observer will be on Earth, the differences in angles which we would
use to determine if a satellite is visible would be less than a degree. This distance is not useful
for tracking however very useful for checking if satellites are visible or not.
