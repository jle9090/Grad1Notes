# Codes
- known seqeuence of 0s and 1s, transmitted at known times
- Legacy codes
	- C/A code: chip rate = $f_0/19-1.923Mcps(MHz)$
		- length = 1ms
		- each gps sat has its own C/A code
	- P code: chip rate = $f_0=10.23 Mcps (MHz)$
		- 37 weeks long, each sat gets a 1 week segment
		- chipped at fast rate

**CODES
- Satellite ID
	- psuedorandom noise - PRN
		- have characteristics of noise
		- irregular structure, but everyone knows it
- CDMA - Code division multiple access
	- all sats are transmit at same radio station, receiver can still select them
	- when tracking one of them, the others do not interfere
	- supresses interference from other sats
	- take a carrier signal, modulate with code, takes signal power in original carrier, spread over bandwidth
		- higher chipping rate = higher bandwidth in freq domain
		- receiver collapses that with correlation process
	- picks up a sat signal by: shift around and see if it aligns, signal power collapses to track it
		- like a matched filter
- Receiver sat range measurement
	- prn code phase is a measure of signal transmission time
